# Фотогалерея - Руководство по использованию

## Что было реализовано

### 1. Фотогалерея (/?page=gallery)

**Основные функции:**
- Отображение всех изображений из папки `/gallery` в уменьшенном виде (150px ширина)
- При клике на фото оно открывается в новой вкладке в полном размере
- Загрузка новых изображений через форму на странице
- Автоматическое создание миниатюр (150x150px с обрезкой до квадрата)
- Ресайз больших изображений до 1200x1200px

**Поддерживаемые форматы:** JPG, PNG, GIF, WebP
**Максимальный размер файла:** 5 МБ

### 2. Логирование запросов

**Функциональность:**
- Каждый запрос к `index.php` автоматически записывается в файл
- Содержит: время, метод запроса (GET/POST), URL, IP адрес
- Пример записи: `09.12.2024 14:23:45 - GET /?page=gallery - IP: 192.168.1.100`

**Размещение:** `/_log/log.txt`

### 3. Ротация логов

**Как это работает:**
1. Запросы записываются в файл `log.txt`
2. Когда в файле накопилось 10 записей, он переименовывается в `log0.txt`
3. Создается новый пустой файл `log.txt`
4. Следующая ротация создаст `log1.txt`, потом `log2.txt` и т.д.

**Архив логов:** `/_log/log0.txt`, `/_log/log1.txt`, `/_log/log2.txt`...

## Новые функции в PHP

### engine/functions.php

**getGalleryImages($directory)**
- Получает список всех изображений из папки
- Возвращает массив имен файлов
- Поддерживает JPG, PNG, GIF, WebP

**buildGallery($directory, $thumbnail_width = 150)**
- Строит HTML для галереи
- Автоматически сканирует папку
- Использует миниатюры если они существуют

**uploadImage($file_input_name, $destination_dir, $max_size, $max_width, $max_height)**
- Загружает изображение
- Проверяет тип файла (MIME)
- Проверяет размер файла
- Ресайзит изображение если оно больше чем max_width x max_height
- Создает миниатюру
- Возвращает результат: `['success' => true/false, 'filename' => '...', 'error' => '...']`

**resizeImage($source_path, $dest_path, $max_width, $max_height, $image_type)**
- Изменяет размер изображения с сохранением пропорций
- Поддерживает все типы изображений

**createThumbnail($source_path, $dest_path, $thumb_width, $thumb_height, $image_type)**
- Создает квадратную миниатюру
- Обрезает изображение в центре для получения квадрата
- Масштабирует до 150x150px

### engine/log.php

**logPageRequest()**
- Логирует текущий запрос
- Вызывается в начале index.php
- Записывает: время, метод, URL, IP

**rotateLogFile($log_file)**
- Проверяет количество строк в log.txt
- При достижении 10 записей переименовывает файл
- Создает новый пустой log.txt

## Использование

### Просмотр галереи
1. Откройте `/?page=gallery`
2. Вы увидите все загруженные изображения в виде миниатюр
3. Кликните на миниатюру для просмотра в полном размере в новой вкладке

### Загрузка изображения
1. На странице галереи заполните форму "Загрузить новое изображение"
2. Выберите файл (JPG, PNG, GIF или WebP)
3. Нажмите "Загрузить"
4. Страница перезагрузится и новое изображение появится в галерее

### Просмотр логов
- Текущие логи: `/_log/log.txt`
- Архив: `/_log/log0.txt`, `/_log/log1.txt` и т.д.
- Каждый файл содержит максимум 10 записей

## Примеры кода

### Использование функций галереи в своем коде

```php
// Построить галерею из папки
$gallery_html = buildGallery('/path/to/images', 200);

// Получить список изображений
$images = getGalleryImages('/path/to/images');
foreach ($images as $image) {
    echo $image . "\n";
}

// Обработать загрузку
if ($_FILES['image']) {
    $result = uploadImage('image', '/path/to/images', 5242880, 1200, 1200);
    if ($result['success']) {
        echo "Загружено: " . $result['filename'];
    } else {
        echo "Ошибка: " . $result['error'];
    }
}
```

### Логирование собственных событий

```php
// Логирование в отдельный файл с суффиксом
_log("Пользователь выполнил действие", 'events');

// Логирование массива
_log(['user_id' => 123, 'action' => 'login'], 'auth');
```

## Технические детали

### Обработка изображений
- Используется GD Library для PHP
- Сохранение прозрачности для PNG и GIF
- Качество JPEG: 90%, WebP: 90%, PNG/GIF: без сжатия

### Проверка файлов
- MIME тип проверяется функцией finfo_file()
- Размер файла ограничен на уровне функции uploadImage()
- Разрешение выполнено через scandir() и расширение файла

### Безопасность
- HTML специальные символы экранируются (htmlspecialchars)
- Генерация уникальных имен файлов (timestamp + uniqid)
- Проверка наличия директории перед записью
- Права на файлы: 0644, на директории: 0755
